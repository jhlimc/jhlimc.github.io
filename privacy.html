개인정보처리방침

manager-widget은 개발자 본인이 자기 PC에서 쓰는 개인용 프로그램입니다.

Google 사용자 데이터 사용

  • Gmail 읽기 권한: 받은 메일을 위젯 화면에 보여 주고 할 일 후보로 정리하는 데만 씁니다.
  • Gmail 보내기 권한: 사용자가 위젯에서 내용을 확인하고 직접 누른 메일만 보냅니다.

저장과 공유

  • 메일 내용과 인증 토큰은 사용자 PC에만 저장됩니다. 개발자 서버나 제3자에게 보내지 않습니다.
  • 광고, 판매, AI 학습 등 다른 목적으로 쓰지 않습니다.
  • Google API에서 받은 정보의 사용과 전송은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

권한 취소

https://myaccount.google.com/permissions 에서 언제든 manager-widget의 접근을 삭제할 수 있습니다.
